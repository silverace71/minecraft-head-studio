What do these layer types do?

Outer shell: add hair, hats, or details that float beyond the original 8×8 head. The golden outlines show the grid even when this layer is blank.

Inside backing: build hidden surfaces behind sliding eyes, or panels that cover exposed gaps. Layer distance is measured inward.
