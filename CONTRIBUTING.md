# Contributing

This is a prototype hobby tool, intended to be tested with real foamboard before any parts are treated as manufacturing-ready.

Please describe issues with a reproducible sequence, a sample public-domain/example skin where possible, and your target resolution/foamboard dimensions. Avoid submitting copyrighted third-party skins without permission.

Run `npm test` and the built-in browser workflow before submitting a PR. Keep the no-runtime-dependencies approach unless a dependency has a compelling benefit.

Good first issues: edge transition around cube corners, expanded-layer physical joins, arrow-key pixel placement/accessibility, sheet nesting, 1:1 multi-page printing, metadata/schema migrations, skin service fallback tests, mechanism collision checks, and improved mobile experience.

By submitting a contribution you agree to license it under GPL-3.0-or-later.
